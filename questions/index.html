Resources

Select Library in the top bar to expand your study collection. Choose an organ system or foundation subject to open its tasks, or choose All tasks to browse the whole curriculum. The resource hub link opens references and source tools. On small screens, Library uses the four-square icon. Press Escape or select outside the panel to close it.

Resources

Expand a task and select Read First Aid pages beside a reading assignment. Choose the edition and page in the reader. Readable text size gives larger text with scrolling; Full page fits the entire page, and Fit page to width gives a page overview. Use Previous and Next or Open full page as needed. Close the reader to return to your task. Only available mapped pages can be shown, and pages are not saved for offline use.

About the planner

Select Page tour near the top of a study page to replay that page’s guided instructions. Use its Next, Back and skip controls to explore at your own pace. Dashboard also has Getting started for the introductory tour. Replaying or skipping a tour does not change study completion.

Planning

The plan editor saves one active schedule used by Dashboard, Current focus and Calendar.

  1. Open the plan editor and answer the starting-point questions, including which read you are planning.
  2. Choose subjects and put them in order. Expand Choose individual tasks & their order to select or reorder tasks within a subject.
  3. Choose a study style, start date, optional desired finish and break weekdays. Review resource choices and reading pace.
  4. Review the preview, then select Save my plan. Check the save message before leaving.

Planning

In the plan editor’s topic step, expand Already completed some of this read? and select whole systems or individual tasks to leave out. This changes the planned work without changing your task checkmarks. Completed resource steps are also skipped automatically. Progress stays separate for each read.

Moving preserves its resources and completion history; split tasks move one day at a time. A manual move can use a rest day. Use Keep date when redistributing to lock or unlock a date. Unlock protected dates before rebuilding a plan.

Flashcards

Flashcard study requires signing in and a connection.

  1. Open Flashcards and select Mnemosyne in the built-in library.
  2. If it is not installed for your account, select Add deck and start studying. No deck upload is needed.
  3. Choose a study day or Focus topic, then select a matching subject or Start reviewing.
  4. Recall the answer, select Show answer, then rate Again, Hard, Good or Easy. Wait for the rating to save before continuing.

Open flashcards →

Flashcards

In Flashcards → Study, change Study day or Focus topic. Choose All tasks for this day to follow the selected calendar date, or Study current focus to return to your current task. Expand Study a topic or build a custom session to choose a subdeck and tag. Include future scheduled reviews adds future cards while daily limits still apply. No matching cards may mean the task has no mapped flashcards.

Open this feature →

Flashcards

After revealing the answer, rate your recall with Again, Hard, Good or Easy so the next review can be scheduled. Space reveals the answer; keys 1–4 select those ratings. Undo reverses the last available rating. Bury today temporarily removes a card from today’s review, while Suspend removes it from normal review until you restore it. Use Browse cards to manage cards, and End review to leave a session.

Open this feature →

Flashcards

Select Browse cards to search and filter the installed deck and manage selected cards. Edit note is also available during review. Use Statistics to inspect review activity and Deck settings to adjust the review settings and daily limits. Changes affect your account’s deck. The Download original deck link provides the separate original Anki deck; browser reviews do not automatically sync to an external Anki installation.

Question bank

Open Question bank → Create test. Choose Tutor or Timed mode, the read/pass and available question filters. Select subjects, systems and categories, choose the question count, then review the test summary before starting. The available bank and active filters determine which questions can be selected. A practice score does not establish exam readiness.

Open the question bank →

Question bank

In Tutor mode, choose an answer and select Submit answer to reveal feedback and explanations for that question. In Timed mode, work through the block before ending the test to review the answers. Previous and Next move between questions. Clear answer removes an unsubmitted selection. Written-response questions use a text box and may require comparing your response with the model answer.

Open this feature →

Question bank

In Create test, use Create test by question IDs to enter the IDs you want, or Retrieve questions from a test to reuse an existing test selection. Task question shortcuts connect study assignments to practice. Open Settings → Question bank to configure task shortcuts and ID display. IDs must match questions available in the bank; an external provider’s ID is not a guarantee of a matching local question.

Use Mark question to flag a question for later review. The cross-out control beside an answer toggles elimination without selecting that answer. Use the test’s tools for lab values, calculator and display preferences. Highlighting depends on the exam display settings. These aids support your practice; marking or crossing out an option does not submit an answer.

Study sessions

Open the focus timer and choose Solo Pomodoro. Select Start focus; use Pause session and Resume focus as needed. Before starting, use the duration controls or Timer settings to change focus minutes, breaks and cycle count. Saving timer settings restarts the current cycle. Choose automatic next intervals only if you want them to start without another click. Session history shows completed focus intervals.

Study sessions

This floating-timer choice is saved on the current device. Review Session history in the same settings section for recorded study activity.

Teams

Teams

Yes. On Team, use Your study plan to choose Follow the team schedule or Follow my own study plan. Use team topics in my study plan opens a personal-plan preview using your own resources, time and breaks. Review and save it to update Dashboard, Current focus and Calendar. Later team edits do not automatically replace that personal plan.

Teams

Use Edit plan on Team to adjust the team schedule, subject order or task pace. Shared-team editing permissions may limit changes to the owner. Export plan file downloads a portable schedule; Import plan file reads a supported JSON or text plan file. Importing replaces this device’s current team plan, so review the selected file and any confirmation before proceeding. A plan file is separate from an invitation code.
